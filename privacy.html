Политика конфиденциальности приложения proxy-top

Дата последнего обновления: 19 ноября 2026 г.

1. Какие данные собирает приложение

Для проверки лицензии и соблюдения ограничения на количество устройств (до 3 устройств) приложение proxy-top запрашивает через Google OAuth 2.0 следующие минимальные сведения:

  • Адрес электронной почты Google (userinfo.email): используется для идентификации лицензированного аккаунта и проверки наличия доступа к файлу лицензии.
  • Доступ к Google Drive (drive): используется исключительно для чтения и обновления конкретного файла лицензии (запись и удаление идентификатора вашего устройства в рамках лимита устройств).
  • Технический идентификатор устройства (HWID) и имя ПК: вычисляется локально на вашем компьютере в виде криптографического хеша SHA-256 и записывается в файл лицензии для контроля лимита подключений.

2. Как используются и хранятся данные

  • Токен авторизации OAuth 2.0 хранится локально на вашем ПК в папке %APPDATA%\proxy-top\token.json.
  • Приложение не просматривает, не индексирует и не скачивает никакие другие файлы с вашего Google Диска, кроме целевого файла лицензии.
  • При нажатии кнопки выхода/смены аккаунта в приложении запись о вашем устройстве удаляется из файла лицензии, а локальный токен стирается.
  • Ваши данные не продаются и не передаются третьим лицам.

3. Соответствие Google API Services User Data Policy

Использование и передача информации, полученной приложением proxy-top через Google API, полностью соответствует требованиям Google API Services User Data Policy, включая требования ограниченного использования (Limited Use).
