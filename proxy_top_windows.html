Стабильный системный прокси-менеджер для Windows

proxy-top — десктопное приложение для автоматического поиска, многопоточной проверки и подключения рабочих HTTP/SOCKS5 прокси с поддержкой локального отказоустойчивого шлюза и раздельного туннелирования приложений.

Многопоточная проверка

Трехэтапный конвейер отбора прокси проверяет задержку, поддержку HTTPS, геолокацию и реальную доступность нужных веб-сервисов.

Локальный шлюз 127.0.0.1

Автоматическое резервное переключение между проверенными узлами без разрыва активных сессий в браузерах и терминале.

Раздельное туннелирование

Выбирайте конкретные программы на ПК, которые должны работать напрямую через ваш домашний интернет в обход прокси.

Использование Google OAuth 2.0

Приложение proxy-top использует авторизацию через Google исключительно для проверки активной лицензии пользователя в файле лицензии на Google Диске и учета лимита подключенных устройств (до 3 ПК). Приложение не читает личную переписку и не собирает сторонние файлы с вашего Google Диска.
